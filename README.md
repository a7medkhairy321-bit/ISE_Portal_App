# ISE Portal

ISE Portal (بوابة ISE) is the attendance and grades app for the Systems Department,
Faculty of Engineering. Students scan the lecture's rotating QR code to be marked
present and see their absences and published grades; lecturers run lectures,
attendance and assessments; the department admin manages courses and accounts.

It is built by a Systems Department student and is **not an official university app**.

This repository only hosts the Android app for download. The source code is private.

## Download

**[Download the latest version (ise-portal.apk)](https://github.com/a7medkhairy321-bit/ISE_Portal_App/releases/latest/download/ise-portal.apk)**

All versions and their notes: [Releases](https://github.com/a7medkhairy321-bit/ISE_Portal_App/releases).

## Which file?

**One file for all phones:** download **`ise-portal.apk`**. It works on every Android
phone running Android 7.0 or newer, 64-bit and 32-bit. There is no other file to choose.

## Install on Android

1. Download `ise-portal.apk` on your phone (link above).
2. Open the downloaded file from the notification or from your **Downloads** folder.
3. If Android says installing unknown apps is blocked, tap **Settings**, turn on
   **Allow from this source** for your browser or file manager, then go back.
4. Tap **Install**, then **Open**, and log in.

New versions install over the old one; your data is kept (it lives on the server).

## Troubleshooting: "App not installed"

- **You have an older test build installed** (signed differently): uninstall ISE Portal
  first, then install the downloaded file and log in again. Nothing is lost.
- **The download is incomplete:** delete the file, download it again, and retry.
- **Not enough storage:** free some space and retry.
- **"Package appears to be invalid" with version 1.0.1 or older:** those releases
  were arm64-only and don't install on phones running a 32-bit Android. Download
  the latest `ise-portal.apk` (one file for all phones) and install it.
- **Your phone runs Android older than 7.0:** the app can't be installed on it.
